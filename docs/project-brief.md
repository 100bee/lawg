# RAGOps Copilot 프로젝트 정의

## 한 줄 소개

기업용 RAG 서비스를 운영하는 AI·백엔드·SRE 팀이 장애 증상과 로그를 입력하면 관련 Runbook과 과거 장애를 검색해 근거 있는 원인 후보와 대응 절차를 제공하는 웹서비스다.

## 가상 운영 환경

가상의 B2B AI 스타트업 `RAGOps Cloud`는 고객 문서를 수집해 문서 기반 질의응답을 제공한다. 서비스는 API Gateway, Ingestion Worker, Embedding Service, Vector Search, Answer Service, PostgreSQL로 구성된다.

## 사용자

- AI 엔지니어: 검색 품질 저하와 모델·프롬프트 변경 영향을 분석한다.
- 백엔드 개발자: API 오류, Worker 실패, DB 장애를 진단한다.
- SRE: 지연시간, 비용, 오류율과 배포 이후 회귀를 확인한다.

## MVP 문제

운영 문서, Runbook, 장애 보고서, 변경 이력이 흩어져 있어 장애 초기 분석에 시간이 걸리고 담당자마다 대응 품질이 달라진다.

## MVP 기능

1. Markdown 운영 문서 일괄 색인
2. OpenAI 또는 로컬 개발용 임베딩 생성
3. pgvector 벡터 검색과 PostgreSQL 키워드 검색 결합
4. 근거 기반 장애 요약과 대응 체크리스트 생성
5. 문서명, 청크, 검색 점수를 포함한 출처 표시
6. 근거 부족 시 답변 거절과 추가 확인 질문 제시
7. 검색 청크, 지연시간, 토큰 사용량을 보여주는 디버그 패널
8. Golden Dataset 기반 Recall@K, MRR, 거절 정확도 평가

## MVP 제외 범위

- 회원가입과 조직별 권한
- PDF·이미지 OCR
- Redis와 작업 큐
- 자동 서버 재시작이나 설정 변경
- 외부 모니터링 서비스 연동
- 멀티 에이전트

## 성공 기준

- Docker Compose로 DB, 백엔드, 프론트엔드를 실행할 수 있다.
- 샘플 운영 문서를 한 번에 색인할 수 있다.
- 대표 질문에서 답변과 근거 문서를 함께 확인할 수 있다.
- 근거가 없는 질문에는 추측하지 않는다.
- 평가 실행 결과에서 검색 지표를 확인할 수 있다.
- 질문별 검색 과정과 지연시간을 UI에서 확인할 수 있다.
