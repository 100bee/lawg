# 오래된 문서 검색 문제

## 증상

최신 버전에서 제거된 설정을 안내하는 과거 Runbook이 상위 검색 결과에 나타났다. 오래된 문서가 질문과 문장 표현이 더 비슷해 벡터 점수만으로는 최신 문서를 이겼다.

## 대응

문서에 적용 버전, 작성일, 상태를 메타데이터로 저장한다. 사용자가 버전을 입력하면 해당 버전과 호환되는 문서를 우선 검색한다. `deprecated` 문서는 기본 검색에서 제외하고, 과거 장애 비교를 요청한 경우에만 포함한다. 동일 주제의 문서라면 최신 문서에 freshness boost를 적용한다.

## 검증

버전 충돌 질문을 별도 평가셋으로 관리한다. 답변 출처에 문서 버전을 표시해 사용자가 최신성 여부를 판단할 수 있게 한다.
