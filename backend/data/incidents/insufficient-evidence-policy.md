# 근거 부족 답변 정책

## 원칙

Copilot은 검색된 문서가 질문을 뒷받침하지 못하면 일반 지식으로 장애 원인을 단정하지 않는다. 검색 결과가 없거나 상위 점수가 기준보다 낮으면 근거 부족 상태로 처리한다.

## 사용자에게 요청할 정보

- 오류 발생 시각과 요청 ID
- 영향을 받은 서비스와 환경
- 배포 버전과 직전 변경 사항
- 마스킹된 전체 오류 메시지
- 재현 절차와 영향 범위

## 에스컬레이션

서비스 소유 팀, 심각도, 확인한 항목, 관련 로그 위치를 포함한 전달용 질문을 생성한다. Copilot은 실제 설정 변경이나 서버 재시작을 수행했다고 표현하지 않는다.
