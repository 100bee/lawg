# 질문당 토큰 비용 급증

## 영향

배포 이후 질문 수는 비슷했지만 입력 토큰 사용량이 약 두 배 증가했다. 답변 정확도에는 뚜렷한 개선이 없었다.

## 원인

검색 후보 Top-K가 5에서 20으로 변경됐고 중복 청크 제거가 적용되지 않았다. 시스템 프롬프트에도 동일한 운영 규칙이 여러 번 포함됐다. 긴 대화 이력을 매 요청마다 전부 전달했다.

## 대응

최종 컨텍스트 청크 수를 제한하고 동일 문서의 중복 청크를 제거한다. 프롬프트 규칙을 한 번씩만 기술하고 대화 이력은 현재 질문 해결에 필요한 범위만 유지한다. 질문별 input token, output token, 검색 청크 수, 모델을 실행 기록에 저장한다.

## 검증

대표 질문 평가셋에서 정확도를 유지하면서 평균 입력 토큰이 감소하는지 비교한다. 비용 감소만으로 성공으로 판단하지 않고 출처 정확도와 거절 정확도를 함께 본다.
