# 임베딩 모델 변경 후 검색 누락

## 증상

모델 변경 배포 직후 신규 질문의 검색 점수가 급격히 낮아지고 정답 문서가 Top-K에 포함되지 않았다. DB에는 문서와 벡터가 존재했으며 SQL 오류는 없었다.

## 원인

질문은 새 임베딩 모델로 변환했지만 기존 문서 청크는 이전 임베딩 모델의 벡터를 유지했다. 서로 다른 임베딩 공간의 벡터를 비교해 의미 있는 유사도를 얻을 수 없었다.

## 대응

임베딩 모델 ID와 차원 수를 각 청크의 메타데이터로 저장한다. 모델 변경 시 새 인덱스에 전체 문서를 재색인하고, 평가셋 검증을 통과한 뒤 검색 alias를 전환한다. 질문과 문서가 항상 동일한 모델 버전을 사용하도록 요청 단위 검증을 추가한다.

## 예방

모델 변경은 프롬프트 변경과 분리해 배포한다. 변경 전후 Recall@5와 MRR을 같은 Golden Dataset으로 비교한다.
